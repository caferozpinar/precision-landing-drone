# precision-landing-drone

Bu repo, proje sürümlerini **klasör bazlı değil commit + tag bazlı** tutar.

## Sürüm modeli

- Her sürüm, repository kökündeki dosyaların bir snapshot commit'idir.
- Sürüm etiketleri Git tag ile verilir (`v0.0.0`, `v0.1.0`, ...).
- `versions/` gibi sürüm klasörleri kullanılmaz.

## Kaynak kapsamı

- Kaynak: `Hassas İniş Kodlar/PrecisionLandSoftware-Teknofest/DRONE SOFTWARE/versions/`
- Hariç tutulan soy: `DroneKit-Kubra`
